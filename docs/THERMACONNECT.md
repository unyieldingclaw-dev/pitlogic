# ThermaConnect protocol reference

PitLogic's ThermoWorks adapter (`src/lib/providers/adapters/thermoworks/`) follows the
ThermaConnect BLE provisioning and MQTT documentation published by ThermoWorks at
<https://github.com/ThermoWorks-Integrations/ThermaConnect>.

That repository is **private and has no license**. Its contents are not redistributed
here. Read it at the source if you have been granted access.

Do not commit copies, excerpts, or screenshots of it to this repository. If you keep a
local copy for development, put it in `docs/private/`, which is gitignored.
